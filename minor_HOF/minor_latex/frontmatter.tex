\section{Approach and reading key}
\begin{multicols}{2}
\subsection{Method}
Each event of the accident time-line is analysed with the \textbf{behavioural approach} (Reason's model of organisational accidents), starting from the \emph{phenotype} (how the event manifests) and going back to the \emph{genotypes} (local conditions and latent factors). For every event we report:
\begin{itemize}
  \item \textbf{one page} with the template compiled in bullet form, following the scheme used in class for Events 1 and 3: human factors pathway on the left, system factors pathway on the right, organisational latent errors on top;
  \item \textbf{one page} of justification, explaining which information of the case text supports each box, the classification of the active error and a short \textbf{cognitive view (CREAM)} of the human contribution.
\end{itemize}
Events 1 and 3 reproduce and complete the solution discussed in class; the other events are our own analysis.

\subsection{How to read the templates}
\begin{itemize}
  \item \textbf{Event}: the event occurs if at least one of the two is present: a failure of a technical defence, barrier or safeguard, or an active human error.
  \item \red{Red boxes}: direct causal chain of the event (active error and/or failure in defence that produced it, with the technical latent error behind it). \textbf{White boxes}: contributing conditions.
  \item \textbf{Top box vs.\ side boxes} (scope of influence): a latent factor that affects only one pathway goes into that pathway's box; a factor that affects both the human and the technical side goes on top.
\end{itemize}
